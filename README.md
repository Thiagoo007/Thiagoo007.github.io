# Thiago Moreira · Portfólio

Desenvolvedor backend e de dados em Brasília. Este repositório publica, pelo GitHub Pages, o meu portfólio e cinco projetos que rodam direto no navegador.

| Projeto | O que faz |
|---|---|
| [Radar de Licitações](radar-licitacoes/) | Painel de editais com cálculo dos prazos do art. 55 da Lei 14.133 em dias úteis |
| [Schema Lab](schema-lab/) | Diagrama, linter de riscos, rollback e dry-run para migrations PostgreSQL/Flyway |
| [Motor de Workflow](motor-workflow/) | Máquina de estados com editor visual, simulador, auditoria e métricas |
| [Guardião LGPD](guardiao-lgpd/) | Detecção e anonimização de dados pessoais em CSV, 100% local |
| [Pousada Manager](pousada-manager/) | Reservas sem overbooking, tarifas, indicadores e chatbot de atendimento |

Cada projeto é um único `index.html`, sem build e sem dependências além do Google Fonts. Cada um tem uma aba **Testes** com os autotestes das regras de negócio e uma aba **Sobre o projeto** explicando a arquitetura.

## Como rodar localmente

Abra o `index.html` de qualquer pasta no navegador, ou sirva a raiz:

```bash
python -m http.server 8000
```
